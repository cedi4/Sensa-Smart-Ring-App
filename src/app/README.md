# This explains the /src/app/ directory of the mobile application code
## src/app/
- Contains the mobile app's screens and navigation routes
## src/app/(tabs)/
- Contains the screens connected to the bottom dock 
## src/app/components/
- Contains reuasble UI pieces for the rest of the app
## src/app/context/
- Contains shared app state that the other screens use
## src/app/database/
- Contains SQLlite database operations
## src/app/services/
- Contains code for communication and data-producing logic
- It will hold the code for the real BLE service later
## src/styles
- Contains styling and color components for other parts of the code base to use
